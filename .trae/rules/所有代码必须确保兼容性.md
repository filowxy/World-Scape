1. 所有代码必须确保兼容性。
2. 不要嫌麻烦，一定要把内容做精做好。
3. 注释要同时有中文和英文的版本。
4. 有关兼容性的内容关键值最好不要用硬编码，除非是必须的。
5. 无需帮忙复制文件。
6. 在需要时一定要使用各种agent来辅助完成任务。
7. 提交再操作：执行任何像 git checkout -f 或 git reset --hard 这类破坏性命令前，必须先 git add -A && git commit -m "备份"。哪怕提交信息随便写，也得先让代码进入历史。
8. 不用强制命令：尽量用 git stash 代替 git checkout -f 来切换分支。git stash 会把你的未提交修改先暂存起来，而不是直接丢弃，安全得多。
